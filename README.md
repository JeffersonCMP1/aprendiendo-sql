# aprendiendo-sql
📚 Repositorio de práctica de SQL Server donde documento mi aprendizaje desde los conceptos básicos hasta consultas más avanzadas.

## Temas aprendidos

- Crear bases de datos y tablas (`CREATE DATABASE`, `CREATE TABLE`)
- Insertar registros (`INSERT INTO`)
- Consultas básicas (`SELECT`)
- Tipos de datos en SQL Server
- Eliminar tablas (`DROP TABLE`)
- Uso de procedimientos del sistema (`sp_tables`, `sp_columns`)
- Ejercicios prácticos de consultas
